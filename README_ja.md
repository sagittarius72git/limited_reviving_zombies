# 制限付きゾンビ復活（CDDA 0.I 移植版）

BN用MOD「Limited_Reviving_Zombies」を Cataclysm: DDA 安定版 0.I-1（Ito-1）に移植したものです。JSON（EOC）だけで動きます。

ゾンビの復活を、禁止ではなく制限します。起き上がったゾンビは死体の損壊度に応じて弱く・遅くなり、二度目は起き上がりません。
対象は species が ZOMBIE のものだけです。

## 変更点

- `REVIVES_HEALTHY` を無効化：万全の状態で起き上がるゾンビがいなくなります。
- 復活時のHPに上限：本体の計算の方が低ければそちらを使うので、弱くする方向にしか働きません。
- 起き上がり直後は転倒＋朦朧：その間に頭を潰せます。
- 死後硬直（`lrz_rigor`）：しばらく移動速度が下がります。
- 復活は1回まで：蘇った個体を倒すと、その死体は二度と起き上がりません。

| 死体の損壊度 | HP上限 | 無力時間 | 死後硬直 | 速度低下 |
|---|---|---|---|---|
| 0（無傷） | 65% | 5秒 | 2分 | -10 |
| 1 | 50% | 12秒 | 5分 | -20 |
| 2 | 35% | 20秒 | 8分 | -30 |
| 3（ボロボロ） | 25% | 30秒 | 12分 | -40 |

復活までの時間は本体のままです。

## 設定

`eoc.json` 冒頭の `lrz_hp_ratio` / `lrz_rise_secs` / `lrz_rigor_mins` で数値を変えられます。`lrz_max_revivals` を 0 にすると、倒したゾンビは起き上がらなくなります。
速度低下の幅は `effects.json` の `speed_mod` です。どちらもワールドの読み込み直しが必要です。

## BN版との違い

- 復活回数は 0 か 1 だけです（CDDA では、蘇った個体に元の死体の記録を引き継げないため）。
- 死体の損壊度は、起き上がった直後のHPから推定します。焼けた死体は損壊が大きい扱いになります。
- 炎や酸の上など、攻撃した相手がいない死に方で倒れた個体の死体は封じられません。
- 蘇った個体は「初めて見つかったときHPが最大の70%以下」で判定します。出現直後に傷を負ったゾンビも、蘇った個体として扱われることがあります。

## 注意

- 既存ワールドにも追加できます。追加前にすでに一度蘇っていた個体は、もう一度起き上がることがあります。追加時点で傷ついているゾンビは、蘇った個体として扱われます。
